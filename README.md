# Lumi Frontend (React)

Lumi 是一个集成了 AI 对话、实时社交、协同观影和视频企划管理的现代化单页应用。核心定位是在 Lumi 这个智能 Agent 的帮助下，让用户更高效地使用平台提供的各项 AI 工具和服务。本项目支持为不同人群个性化定制功能，是一个集各种 AI 工具为一体的综合性站点。基于 React 19、TypeScript 和 Vite 构建，致力于提供流畅、美观且功能丰富的用户体验。

## 🚀 产品更新日志 (v0.5.0)

本次更新主要集中在 **多媒体协同** 和 **移动端体验优化**，同时增强了 **AI 对话** 和 **即时通讯** 的核心能力。

### ✨ 新增功能

#### 1. 🎬 浪漫放映室 (Watch Party)
- **核心功能**：支持用户创建专属放映室，上传视频并与好友实时同步观看进度。
- **协同播放**：基于 WebSocket 实现秒级同步，支持播放/暂停/进度跳转的实时广播。
- **视频上传**：集成了大文件上传能力，支持自动播放和错误处理。
- **体验优化**：
  - 重新设计了卡片式布局，增加情感化 UI 元素（渐变背景、动效）。
  - 实现了移动端适配，确保在手机上也能完美体验协同观影。

#### 2. 📋 视频企划 (Video Planner)
- **核心功能**：为创作者提供的视频灵感与任务管理看板。
- **任务管理**：支持任务的创建、编辑、状态流转（待办/进行中/已完成）。
- **AI 辅助**：集成 AI 生成能力，一键生成视频企划案。
- **移动端适配**：
  - 针对移动端优化了看板布局，支持横向滚动。
  - 按钮组在小屏幕上自动折叠和排版，提升操作便捷性。

#### 3. 🤖 AI 对话升级
- **流式响应**：优化了 SSE 流式传输处理，打字机效果更流畅。
- **多模式切换**：支持代码生成、创意写作、深度思考等多种对话模式。
- **界面优化**：统一了输入框样式，移除最大宽度限制，提供更沉浸的对话视野。

#### 4. 💬 用户即时通讯
- **好友系统**：完整的好友添加、接受、拒绝流程。
- **实时聊天**：基于 Socket.IO 的私信功能，支持在线状态显示。

## 🚧 开发挑战与解决方案

在本次迭代过程中，我们遇到并解决了以下关键技术问题：

### 1. 移动端布局适配
- **问题**：在“视频企划”和“浪漫放映室”页面，复杂的桌面端布局在手机上显示拥挤，按钮溢出屏幕。
- **解决**：
  - 采用 **响应式 Flex 布局**，在移动端将水平排列（`flex-row`）切换为垂直排列（`flex-col`）。
  - 引入 **水平滚动容器**（`overflow-x-auto`），确保工具栏在小屏幕上完整可访问。
  - 动态隐藏非必要装饰元素，最大化内容展示区域。

### 2. 视频自动播放策略
- **问题**：浏览器限制视频在无用户交互下的自动播放，导致上传后无法直接开始。
- **解决**：
  - 在上传成功的回调中显式触发播放状态更新。
  - 添加 `muted` 属性作为自动播放的降级方案（虽本次主要通过状态控制）。
  - 完善 `onError` 事件监听，为用户提供明确的加载失败反馈。

### 3. WebSocket 连接稳定性
- **问题**：在开发环境下，Vite 的代理配置导致 Socket.IO 连接频繁断开或握手失败（EPIPE/ECONNREFUSED）。
- **解决**：
  - 调整 `vite.config.ts` 中的代理规则，确保 WebSocket 流量正确转发。
  - 在客户端实现心跳检测和自动重连机制，增强连接韧性。

### 4. 状态同步与管理
- **问题**：AI 对话流式输出与本地状态的同步容易产生竞态条件，导致消息闪烁或丢失。
- **解决**：
  - 重构消息存储逻辑，引入临时 ID 和服务器 ID 映射机制。
  - 明确消息状态流转（Sending -> Streaming -> Synced -> Failed），确保 UI 渲染的确定性。
